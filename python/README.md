# Python Programming for SRE, DevOps and Platform Engineering

A 120-chapter, lab-driven curriculum from Python fundamentals to production automation.

## Learning path

| Part | Chapters | Subject |
|---|---|---|
| 01 | 001–010 | Fundamentals and syntax |
| 02 | 011–020 | Data types, collections and algorithms |
| 03 | 021–030 | Functions, modules and packages |
| 04 | 031–040 | Object-oriented programming |
| 05 | 041–050 | Files, exceptions, logging and configuration |
| 06 | 051–060 | Advanced Python, typing and concurrency |
| 07 | 061–070 | Testing, debugging and code quality |
| 08 | 071–080 | APIs, networking and databases |
| 09 | 081–090 | DevOps, SRE and automation |
| 10 | 091–100 | Kubernetes, AWS, Azure and GCP |
| 11 | 101–110 | Production security and performance |
| 12 | 111–120 | Enterprise capstone projects |
