| 07 | 061–070 | Testing, debugging and code quality |
| 08 | 071–080 | APIs, networking and databases |
| 09 | 081–090 | DevOps, SRE and automation |
| 10 | 091–100 | Kubernetes, AWS, Azure and GCP |
| 11 | 101–110 | Production security and performance |
| 12 | 111–120 | Enterprise capstone projects |
