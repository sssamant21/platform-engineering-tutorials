# Chapter 085 — Enterprise security and DR runbooks

1. **Incident command:** classify, assign incident commander, freeze change and preserve logs.
2. **CI/OIDC compromise:** isolate runner, revoke sessions, verify exact trust and blast radius.
3. **Cloud IAM rollback:** inspect SCP/permission boundaries, Azure RBAC, GCP WIF and break-glass.
4. **OPA/Sentinel failure:** fail closed, verify signed bundle and enforcement level.
5. **Secret leak:** revoke/rotate, audit Git history, state, logs and affected services.
6. **Supply-chain attack:** quarantine artifact, validate trusted builder and rebuild.
7. **Kubernetes RBAC/admission:** inspect ServiceAccount, webhook, Pod Security and CNI.
8. **GitOps drift:** restore one controller owner and protected source reconciliation.
9. **State backend:** inspect encryption, KMS, versioning, lock and restore state.
10. **Database PITR:** test KMS decrypt, backup, restore, replica lag and RPO/RTO.
11. **Stateful recovery:** verify MongoDB quorum, Redis failover, Kafka ISR, OpenSearch snapshots.
12. **Audit/acceptance:** measure SLO, attach evidence, review exceptions and obtain signatures.
