# Chapter 095 — Enterprise observability and reliability capstone architecture

**Source:** protected Git, approved change, immutable plan, state backend version.

**Observation:** OTel, Prometheus, provider audit, Kubernetes/GitOps, read-only AWS/Azure/GCP inventory and DBRE data-plane metrics.

**Trust:** provenance, UTC time, completeness, freshness, redaction, cardinality and separation of duties.

**Intelligence:** three-way desired/managed/actual drift, change-to-incident candidates, alternate hypotheses.

**Reliability:** request SLIs, 30-day SLO, error budget, multi-window burn alerts and real paging.

**Safety:** HOLD/QUARANTINE, independent approval, canary, circuit breaker, no destructive auto-apply.

**Closure:** real database restore, measured RPO/RTO, SLO, zero orphans, audit and SRE/DBRE/security acceptance.

**Lab boundary:** synthetic offline JSON; native acceptance not established.
