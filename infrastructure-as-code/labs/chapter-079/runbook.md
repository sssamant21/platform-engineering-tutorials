# Chapter 079 — Production SRE/DBRE runbooks

1. **Change preflight:** signed source, ticket, inventory, context, namespace, resource owner.
2. **Identity:** OIDC claims, RBAC, become scope, Vault and redaction.
3. **Ansible:** inventory, check-mode caveats, serial rollout, handlers, idempotency.
4. **Kubernetes:** readiness, PDBs, quotas, CSI volumes, admission.
5. **GitOps:** desired Git revision, Argo/Flux health, sync windows and prune.
6. **Promotion:** immutable digest, staging evidence, SRE/security/DBRE approval.
7. **DBRE:** PITR, backup checksums, replica lag/quorum, RPO/RTO, restore drill.
8. **Partial deployment:** freeze, preserve logs, inspect actual state.
9. **SLO:** stop on latency, errors, lag or saturation; choose safe recovery.
10. **Handover:** provenance, diff, approval, metrics, backups, incident timeline.
