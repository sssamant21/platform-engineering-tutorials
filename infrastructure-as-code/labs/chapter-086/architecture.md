# Chapter 086 — Testing architecture

**Source and static:** format, syntax, secrets, SBOM, IaC scans.

**Unit and policy:** Terraform test, Pulumi mocks, OPA/Sentinel tests, CloudFormation Guard, Ansible Molecule and negative cases.

**Plan and integration:** immutable artifact, protected OIDC, native plan/preview, isolated cloud/cluster integration, teardown and cost.

**SRE/DBRE:** test PITR, KMS recovery, MongoDB quorum, Redis failover, Kafka ISR, OpenSearch snapshots and SLO.

**Evidence:** tool versions, source SHA, target, run logs, policy bundle, independent approvals and cleanup.
