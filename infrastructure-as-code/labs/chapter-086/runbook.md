# Chapter 086 — Testing SRE/DBRE runbooks

1. **CI failure:** classify tool, environment, regression and ownership.
2. **Terraform/OpenTofu:** inspect state, provider lock, plan delete/replace and target.
3. **Pulumi/CloudFormation/Bicep:** validate preview/change set/what-if and policy.
4. **Ansible:** isolate inventory, run syntax/lint/Molecule and audit become.
5. **OPA/Sentinel:** replay negative tests, inspect policy bundle and enforcement.
6. **Kubernetes:** verify admission, RBAC, CNI, namespace and server dry-run.
7. **GitOps:** reconcile source, controller ownership and rollback.
8. **Ephemeral cleanup:** identify resource TTL, state locks, finalizers and cost.
9. **Secrets:** quarantine CI logs, revoke/rotate, preserve evidence.
10. **DBRE restore:** verify backup, KMS, PITR, RPO/RTO and application health.
11. **Canary:** monitor SLO/error budget, halt and rollback safely.
12. **Audit:** attach native logs, negative tests, cleanup and signed approval.
