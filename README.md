# Platform Engineering Tutorials

Hands-on tutorials and SRE runbooks for operating cloud-native platforms.

## Tracks

- [Kubernetes Administration](kubernetes/README.md) — 105 chapters, including EKS, AKS and GKE.
- [OpenShift Container Platform Administration](openshift/README.md) — 18 chapters on enterprise OCP operations, cluster health, Operators, security, upgrades, and recovery.

Both tracks emphasize reproducible labs, troubleshooting, security, observability, high availability, upgrades, disaster recovery and operational acceptance criteria. OpenShift chapters focus on Red Hat-specific cluster administration rather than repeating Kubernetes fundamentals.
