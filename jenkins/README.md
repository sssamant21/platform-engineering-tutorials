## Tutorial standard

Each chapter: objectives, architecture, production scenarios, executable examples, hands-on labs with expected results, troubleshooting, operational runbooks, rollback and acceptance criteria. Lab counts should reflect meaningful exercises, not filler.

## Safety and publication

Use isolated agents for untrusted builds, least-privilege identities, reviewed Jenkins Configuration as Code, pinned plugins and controlled backups. Do not assume standard Jenkins supports active/active controllers sharing one writable JENKINS_HOME. Use disposable environments for experiments. Publish one complete chapter and companion lab at a time, then update this master index and STATUS.md.
